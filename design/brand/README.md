# Pocket identity

Original artwork for this project: a pocket outline around a terminal prompt.
The open top and pointed lower seam signify the mobile companion; `>_` keeps
the mark recognizable as a coding tool at small sizes. No OpenAI or DSH Go
logo or source artwork is included.

Neutral graphite `#202123` and warm white `#F8F8F7` match the app's restrained
Codex-inspired theme. The inverse variant is for dark surfaces. The default
launcher remains graphite to retain recognition across launchers.

`pocket-mark.svg` and `app-icon.svg` are editable vector sources.
`python scripts/build-icons.py` regenerates the Android adaptive, monochrome,
notification and fallback resources, Windows multi-size ICO, PNG and preview.
Android adaptive foreground fits the central safe area; the system controls
the outer mask. Notification artwork has a transparent background.
