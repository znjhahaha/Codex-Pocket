# Codex Pocket 0.5.3 验收记录

日期：2026-11-08。Android 0.5.3 / versionCode 8；Windows 助手沿用兼容的 0.5.2。本轮未提交或推送 Git。

## 范围

- Inter 与中文系统回退，共享正文、计划和文件阅读排版；代码及差异默认换行，工具摘要单行。
- 左侧缩略导航重设计：Codex 式细栏等距排列用户消息；触摸和拖动预览保持 24dp 宽度，长按／拖动后松手跳到所选提问。短按释放切换为 BaoCode 式彩色缩略图：展开预留 48dp，缩略墨色宽 24dp，玻璃滑块宽 30dp、圆角 7dp。每条用户消息只有一条暖色横标，正文使用有界的真实换行与长度样本，不重复三条线填满段落。覆盖全部已加载可见条目，超密集段按像素带合并，隐藏过程不展开。正文同步让位；2.5 秒无操作后收起。滑块采样独立缩略墨色层，轻微折射、细高光和阴影限制在小圆角矩形内，按住轻微形变并回弹。
- 滚动时复用几何与文本样本；240ms 宽度过渡缩放已有轮廓，不逐帧遍历和解析全文。拖动定位不超过每 50ms 一次，松手重新测量最终位置；可用高度改变会取消旧手势，避免旧坐标误跳。
- 成功任务收拢过程，保留最终文本和方案，历史工具失败有标记；待处理请求保持可见。
- 计划预览、独立反馈草稿、跳过与重开；确认卡替代普通输入框，修复底部滚动反馈循环。
- Fast 改为模型面板右上角闪电，保留能力校验和提交去重。
- 首页与会话顶部控件使用独立清透材质：模糊从 11dp 降为 4.5dp，浅色遮盖约 32%、深色约 38%；保留边缘高光。编辑器、正文、差异和审批可读底色不受该局部配置影响。

## 性能边界

本地确定性 1,000 条消息＋200 个工具样本。滑块外观微调前、设备无并发构建的独立测量（每项预热 3 次、20 次采样）：首次缩略图构建 P95 **6.804ms**、复用样本缓存重建 **1.835ms**、细栏轮廓 **0.415ms**、展开轮廓 **0.767ms**。这些是映射及几何操作耗时，不是整页响应耗时；拖动和宽度动画复用几何，不逐帧重复构建。

上一版 MuMu 混合帧采样（首次布局、跳转和六次拖动）共 30 帧，P50 **32.74ms**、P95 **269.04ms**，超过刷新预算的样本占 **70%**。此前较早版本或并发构建期间数据分别保留于报告，不能作为严格 A/B。当前仍有慢帧，**未达到也不能替代真机性能目标**；该混合采样不是纯滚动掉帧率。缓存会话切换 P95 本轮未测。

本次窄列版本在无并发构建下单独测量：映射首次构建 P95 **4.808ms**、复用样本缓存 **1.690ms**、收起几何 **0.478ms**、展开几何 **0.911ms**。混合帧采样 36 帧，P50 **29.23ms**、P95 **187.60ms**，超过刷新预算占 **66.7%**；不能据此宣称纯滚动掉帧率达标，也不构成严格 A/B。原始记录：`.local/v053-device-proof/baocode-shape-performance/report.json`。
