## 待独立验收

- CLI 真实历史，以及实际失败会话的隔离。
- 原生生成、队列／Steer、停止和审批等控制操作的完整闭环。
- Mate 70 Pro 的硬件玻璃、扫码、中文输入、后台与网络切换。
- HMS 真实通知送达和完整 24 小时稳定性。
- 1,000 条消息、200 个工具条目的真机性能目标。

上游服务拒绝或失败不作为控制能力通过的证据。设备页在线也不等于完整会话可用。
本地测试默认使用确定性夹具；真实设备与模型请求必须显式启用。

只读 `LiveBrowseTest` 需显式传入 `liveBrowse=true` 和 `projectCwd`，可用
`longThreadId` 指定要优先检查的长会话。`switches=20`、`dwellSeconds=120`
控制切换次数和停留时间。会修改专用测试会话的用例还需要明确的 `fixtureCwd`，
历史默认工作区和会话 ID 已从公开脚本中移除。稳定性脚本的 `HealthUrl` 也须由使用者提供。
