- 会话权限区分原生能力初始化、旧桥接待更新、读取失败及已确认自定义权限；更新需权威证据。

- 子代理运行计数结合已验证状态和有序生命周期事件；旧连接、迟到元数据与终态回退有本地回归。

原生额度读取需要新的 Windows 助手和桥接能力。已经运行的旧 Codex 桥接进程在重启前可能显示能力不支持或来源未关联，不能由手机猜测账户。第三方来源只使用电脑上已有的启用配置，不向手机传输脚本、请求头或凭据。

普通异步问题保留原生消息协议。带敏感字段的异步问题因缺少私密传输，提示在电脑端处理，手机不通过普通消息提交秘密；阻塞问答的秘密输入只保留在内存。

旧缓存的超大工具记录不会再阻止配对身份初始化和会话目录显示：普通读取超出 SQLite CursorWindow 时，使用事务内分块读取恢复完整文本与原始记录。模型同步的字段合并与版本保护已有本地回归，桌面仅调整选择后的即时双端同步仍待独立实测。

- CLI 真实历史，以及实际失败会话的隔离。

上游服务拒绝或失败不作为控制能力通过的证据。设备页在线也不等于完整会话可用。
本地测试默认使用确定性夹具；真实设备与模型请求必须显式启用。

只读 `LiveBrowseTest` 需显式传入 `liveBrowse=true` 和 `projectCwd`，可用
`longThreadId` 指定要优先检查的长会话。`switches=20`、`dwellSeconds=120`
控制切换次数和停留时间。会修改专用测试会话的用例还需要明确的 `fixtureCwd`，
历史默认工作区和会话 ID 已从公开脚本中移除。稳定性脚本的 `HealthUrl` 也须由使用者提供。
