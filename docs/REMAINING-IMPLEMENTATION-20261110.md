## 1. P0：安装、真实交接及旧用户生效

- 在应用内呈现快捷方式、自启动、后台、桥接、防火墙分项状态；详情、脱敏诊断、固定动作重试复用操作 ID 与安装锁。
- 保留唯一入口、稳定图标、旧快捷方式归属校验；覆盖首装无配置、COM 分阶段失败、WebView2 确认缺失、中文/空格路径、权限和占用。控制服务先启动，再读取/初始化线路；读取失败不得冒充空配置。
- 接通真实 HandoffBackend：受认证维护协议、停止新写、保存回执/游标、释放旧后台、启动并核验新代次、失败回滚。supervisor 持久维护态阻止拉起旧 agent。
- 核验用户、路径、清单、PID/创建时间；UI/supervisor/agent/bridge/Runtime Host 独立展示安装与运行代次。健康检查包含控制协议和 routes/read。
- 旧后台不支持安全退出、旧 bridge 持有原生 stdio 时等待重启，不强杀原生 Codex/CLI/模型任务。宿主升级等空闲；手机显示更新阶段并自动恢复。
- 当前有效安装由稳定启动器解析；登录只启后台和托盘，手动开窗单实例，关闭窗口保连接。实际登录单独验收，不自动注销用户。
- 防火墙路径升级受控更新并保留回滚；限制已验证程序、必要 TCP 端口、专用网络和 LocalSubnet。

## 2. P1：Runtime Host 产品基础

- 将 client/protocol/描述符校验拆为完全不依赖 agent 的 pocket-runtime-ipc，agent 与宿主共同依赖，消除包依赖环。
- 加入根构建、安装清单和运行代次；Broker 附着宿主并保留现有 Desktop/CLI 发现。每配置档案一个宿主，复用现有配置/认证；手机/界面/远控关闭不结束原生任务。
- 先订阅再回放，缺口读快照；连接断开不等于原生死亡，不重复启动。逐项可信核对才解除 reconciliationRequired。
- 冷恢复不持久化问题/答案/原始结果，不重放未知命令。空闲十分钟且无活动/待答/未知操作才允许退出，随后恢复原协调会话。

## 3. A 线：完整 CLI 个人助理

- 每电脑稳定身份、每档案长期协调会话、任务独立原生 thread/turn；发送前持久任务/租约/操作/事件映射。
- 使用真实模型目录及会话指令；协调只读、有限动态工具，绑定宿主代次、协调 thread/turn 与权限。手机不得注入任意原生 RPC/配置/权限；执行任务沿用项目授权，人工审批不代批。
- 默认三执行任务并行；按实际目录处理大小写/别名/符号链接及父子目录写互斥。仅推进交办/托管任务。
- 用户接管撤销调度资格，对托管活动轮次发原生中断而非杀进程；解除接管不自动重跑。恢复先核对不重发。
- 事件按会话合并、协调串行、自身输出不循环唤醒；空闲不调用模型。默认完成/失败/待用户通知，重复合并。
- 手机底栏右侧 60dp 开口口袋+四芒星原创按钮；聊天复用图片/问答/变更卡，任务/成果/原会话入口；桌面状态与暂停。
- 人格、语气、模型、通知、记忆与定时设置；明确指令才写记忆，可编辑/删除并清理索引缓存，不删原生历史。
- 定时一次/每日/每周/固定间隔，固定创建时区；DST 缺失时间跳过、重复时间一次；离线错过不补跑，提醒合并一次。
- 关闭窗口、停止远控、暂停助理独立。验收手机交办→执行会话→进度→问题/审批→成果→原会话；假 app-server 与真实模型验收分开。

## 4. B 线：P2P、LAN、重连与生产中继

- 锁定 libdatachannel/libjuice，Rust/JNI 接入构建和安装；Android arm64+x86_64、R8、库加载回退、许可清单。
- 传输区分已接受/暂不可写/关闭；TLS 仅重试未接受字节。可靠有序，块≤16KiB且≤协商上限，有界队列/高低水位，溢出关闭候选。
- 信令走已有认证加密通道，绑定设备/协商ID/网络代次/有效期，拒绝过期、重复、跨设备。DataChannel 后仍原有 TLS pin、hello、游标恢复。
- p2p.v1 独立能力与候选，不向旧 lan/cloudflare/relay 列表塞新类型。自动模式、可关闭/替换 Cloudflare STUN；不部署 TURN；无认证引导链路不承诺新建公网 P2P。
- 冷启动 LAN 先行250ms再并行中继；温重连最近成功线+有效LAN，前台最多两候选。中继先可用，后台直连稳定30秒及认证/同步后切换。
- 单业务写入口；在途写完成或核对不重发。手动/前台/网络恢复立即试，旧代次回调隔离、有界退避。完善DHCP/VPN/多网卡/睡眠/mDNS降级和偏好与实际路线分别显示。
- 生产修改已授权。先核验现部署与分阶段数据；必要改动先同机隔离候选，再切新连接，保留旧版本和配置回滚。保持基础地址、配对、认证、WSS兼容；不新增匿名入口或记录密文内层内容。新增费用/地址迁移另问具体选择。
