- 将 client/protocol/描述符校验拆为完全不依赖 agent 的 pocket-runtime-ipc，agent 与宿主共同依赖，消除包依赖环。

- 先订阅再回放，缺口读快照；连接断开不等于原生死亡，不重复启动。逐项可信核对才解除 reconciliationRequired。

## 3. A 线：完整 CLI 个人助理

- 每电脑稳定身份、每档案长期协调会话、任务独立原生 thread/turn；发送前持久任务/租约/操作/事件映射。
- 使用真实模型目录及会话指令；协调只读、有限动态工具，绑定宿主代次、协调 thread/turn 与权限。手机不得注入任意原生 RPC/配置/权限；执行任务沿用项目授权，人工审批不代批。
- 默认三执行任务并行；按实际目录处理大小写/别名/符号链接及父子目录写互斥。仅推进交办/托管任务。
- 用户接管撤销调度资格，对托管活动轮次发原生中断而非杀进程；解除接管不自动重跑。恢复先核对不重发。
- 事件按会话合并、协调串行、自身输出不循环唤醒；空闲不调用模型。默认完成/失败/待用户通知，重复合并。
- 手机底栏右侧 60dp 开口口袋+四芒星原创按钮；聊天复用图片/问答/变更卡，任务/成果/原会话入口；桌面状态与暂停。
- 人格、语气、模型、通知、记忆与定时设置；明确指令才写记忆，可编辑/删除并清理索引缓存，不删原生历史。
- 定时一次/每日/每周/固定间隔，固定创建时区；DST 缺失时间跳过、重复时间一次；离线错过不补跑，提醒合并一次。
- 关闭窗口、停止远控、暂停助理独立。验收手机交办→执行会话→进度→问题/审批→成果→原会话；假 app-server 与真实模型验收分开。
