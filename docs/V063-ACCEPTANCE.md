# 0.6.3 连接引导与验收

日期：2026-11-09。目标版本 Android 0.6.3 / code 13，配套 Windows 0.6.3。

## 修复与流程

新安装用户没有选择连接方式时，旧 `pair_device` 将无线路错误映射成 `helper_unavailable`。该用户的诊断显示监督与助手进程仍在运行，不能据此判断为助手崩溃。

本轮增加连接引导：自动检测局域网 → 可选公网（Cloudflare／服务器／暂不配置） → 就绪检查 → Codex 状态 → 手机二维码。局域网无需手动选择，正常配置使用 automatic 策略优先局域网并回退公网；保留显式防火墙授权和高级网卡调整。Cloudflare 默认临时隧道并保留固定域名入口，自建中转提供已有地址与 SSH 部署。

配对门槛核验当前助手与监督心跳、已配置线路、匹配的实际线路证据。回环网关不能单独算手机可用线路；Cloudflare 还需当前隧道已连接且公布地址一致。配对完成与线路就绪分别展示。

诊断 schema 3 增加路线数量、类型、阶段及隧道就绪信息；不导出路由标识、URL、房间、令牌、SSH 认证或聊天内容。手动中转地址只接受不含凭据的 WSS 基础地址，房间由当前电脑身份补齐；保留其他线路。

自动局域网配置增加 `autoLan` 可选字段：新引导启用，旧配置默认关闭以保留手动绑定。助手每 10 秒检查私网地址，变化时保留端口、发现设置和公网线路并刷新；无变化不重建。显式高级网卡调整关闭自动绑定。防火墙授权仍限已校验程序、固定 TCP 端口、Private 网络与 LocalSubnet，兼容 DHCP 地址变化，不开放 Public 网络。

审查补修：相同配置重复保存不再重建线路；过期 LAN 不再遮蔽有效本地监听；同名中转地址变更时，旧连接回调不得证明新地址就绪；LAN 地址规范化后进入配对载荷。
