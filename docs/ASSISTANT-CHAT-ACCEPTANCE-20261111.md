# 助理直接聊天改版验收（2026-11-11）

## 交付范围

Android 助理改成单一聊天主界面：浅灰背景、左右气泡、固定输入栏、按需展开的项目/任务/记忆/定时工具，以及更多菜单。待确认事项提供直接跳转；任务默认紧凑显示，详情、暂停与原会话入口展开后出现。新增原创助理头像及十二个矢量操作图标，浅色和深色使用局部色彩。

草稿在子页切换及退出/重开助理后保留；发送回执只清除相同草稿，新输入继续保留。离线允许编辑，发送仍受原有状态和权限约束。普通聊天不代替审批。当前电脑/运行入口分别保存界面状态。

已有会话深度链接继续由原绑定解析，返回原会话、记忆、定时与设置继续使用现有后端。未增加没有后端支持的语音、附件或自动执行入口。
