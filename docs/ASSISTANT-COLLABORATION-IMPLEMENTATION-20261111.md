# 助理协作架构与界面改造

基线：`70c4ae6` / 0.6.6；分支：`codex/assistant-collaboration`。本文件描述本次候选实现，验证结果另见 `ASSISTANT-COLLABORATION-ACCEPTANCE-20261112.md`。早期助理改版和其他工作目录的设备记录不能替代本次验收。

## 单一聊天与玻璃控件

主聊天自动分工，也允许指定成员或任务进行补充。相关任务合为一条默认收起的摘要，展开后显示任务、负责人、原生子代理及会话入口。独立交付保留成员署名；需要综合的任务组将成员明细留在详情，主聊天展示综合结果。当前问题直接在聊天回答，完成的问题折叠保留。

顶栏、返回/更多控件、待处理提示和输入栏复用现有 `PocketGlassSurface`。正文使用独立 `layerBackdrop`，玻璃控件作为同级浮层读取它，避免将自身捕获到背景中。正文可滚动到控件后方，内容边距随顶栏和输入栏实测高度调整。输入栏处理 IME 和导航栏 inset。正文保持清晰，用户气泡沿用中性主题，紫色限于局部强调。

顶栏和输入栏尺寸随阅读位置保存，避免返回详情时首次测量的零占位把靠近末尾的阅读位置推走。通用控件的纯色背景源直接绘制当前主题颜色，去掉无内容的中间录制层；真实页面、聊天与浮层的内容采样保持独立。该调整消除了本次 MuMu 滚动到历史问答时复现的原生渲染崩溃，设备复验见验收记录。

复用玻璃组件已有硬件、系统版本、省电和高对比度降级逻辑；展开/收起遵循减少动画偏好。后台消息不强制滚动至末尾，提供新消息提示；返回详情恢复草稿、阅读位置与展开状态。

## 成员、任务、执行分离

- 成员持有职责、所属主对话、目录授权和原生会话引用；成员只在同一主对话中复用。
- 任务持有目标、任务组、负责人、依赖和完成标准；每次执行单独记录。一次性任务可以不创建成员。
- Coordinator 负责分工，Execution 负责执行；原生父子代理关系独立于业务成员归属。
- 继续原生会话前核对目录、权限、运行时代次和停止证据。旧会话动态工具能力不会因 resume 被虚假升级；需要新能力时关联新会话并保留历史。
- 运行上限为三个托管任务，沿用目录写入互斥；同一成员的执行串行。
- 改派在旧执行确认停止后更换运行，保留原 Task ID、依赖与组关系。历史结果使用执行时的成员归属。
- 组提交且相关任务结束后只入队一次综合唤醒。待回答不算完成；失败、取消可结束屏障，依赖失败不会继续派发。

补充消息持久化并以单调序号排序。只有能力验证通过时使用原生追加；明确拒绝或不支持则安全排队，回执不确定时先核对，不盲目重复提交。补充创建回退任务后，其排序约束持续到该任务和相关运行结束，后到的原生追加不能越过它；同目标匿名回退任务也串行。已确认的连续原生追加无须等待整个执行结束。显式暂停、旧消息取消和命令回执原子提交；内部改派仅保留本次改派消息。重启后核对原执行与持久记录。任务组也等待结束前接受的补充工作，随后只发起一次综合。

## 接口兼容

- `assistant/prepare`：无须手机指定 runtime，幂等准备现有 CLI，返回准备状态及恢复动作。
- `assistant/read`：返回成员、任务组、任务归属、补充送达、问题历史及有来源的事件；支持 `after` 增量、`before` / `limit` 历史分页、`taskId` 详情。
- `assistant/send`：允许 `memberId` 或 `taskId`，原 `threadId` 保持项目关联语义。
- `assistant/respond`：只应答仍活动的真实请求。用于阅读的历史卡片不能产生审批或新的待回答请求。
- 协调工具提供成员创建/查询/停用、任务关联和任务组提交。旧数据保留原标识和消息。

## 静默准备 CLI

启动交接完成后准备 Runtime Host；已保存的配置优先，失效时报告具体恢复动作，不能静默切换其他账号。首次发现读取标准配置目录与 CLI 安装位置，解析 npm/Volta/Pocket 包装器背后的原生程序，排除自身递归启动。发现过程不执行包装器脚本。

运行时准备与模型执行分离。登录状态来自只读原生账号证据；缺少 CLI、配置、登录状态分别返回可操作的失败原因。重复准备复用现有 Host。准备行为不创建模型轮次。

## 历史问答、链接和图片

仅在原生返回证明所属会话与记录路径后，读取对应原生记录补齐缺少的已完成问答，使用 thread / turn / call 标识关联，保留多次提问及后续纠正。原生卡片优先；完整快照独立去重，项目分页按请求游标记录前页 canonical ID。所有历史响应（包括 resume/fork）统一进行敏感回答脱敏，补充卡片与原生回执核对分离。

用户文本共用会话链接解析，显示图标和标题，支持打开/复制；未知标题使用标签，裸链接显示“打开会话”。链接标题使用外层可点击文本范围，仅图标使用行内占位，标题与后续正文按实际容器宽度连续换行。代码块和文件引用保留原解析路径。

图片优先使用原生消息中经授权的本机路径，缓存图片字节并返回按所属会话隔离的媒体引用。原生 item ID 与原始记录 ID 不同也不靠截断、顺序或时间猜测。绑定缓存持久化，重启/重连续取时重新核对归属和授权；支持清理失败缓存与逐图重试。

这部分媒体修复运行于电脑助手。MuMu 使用新版 APK、电脑助手仍为 0.6.3 时，用户本机截图仍可能收到旧版无法恢复的媒体引用；需要电脑端一起更新。原始截图无需重新发送。

## Windows 自动检查

仪表盘、托盘和诊断快照只读取登录任务缓存；未知、检查中或过期均不能被当作“已关闭”。通过“核验登录任务”显式取得有效证据后才允许切换。安装器能力的自动检查改为原生文件完整性校验，只赋予手动核验资格；协议解析和修复仍在用户操作时执行。保留文件所有权、代次、固定参数、单次执行和未知结果的同 ID 核对约束。后台不再定期运行上述 PowerShell 探测。

## 验证边界

调度、回执、Host 启动使用受控运行时，不触发真实模型生成。当前对话历史及七张本机图片仅用于只读探针。禁止将 Robolectric 渲染或局部协议测试写成真实手机验收；真实手机的玻璃模糊/折射、键盘、大字体、减少动画和导航仍需相应设备证据。
