# CLI 原生能力验证边界

此文件名供 Windows 交付清单兼容使用，不包含个人会话 ID、机器路径或原始运行时输出。

CLI 接入复用电脑原生 daemon，功能以该运行时提供的协议和能力为准。桌面端历史测试成功不能推断 CLI 的所有能力也成功。

## 本地验证

源码包含本地传输发现、分帧、Windows socket 身份校验、包装器和命令去重等回归测试。默认测试使用本地夹具，不应发起真实模型请求。

## 真实验证

需要针对一个明确的测试工作区逐项验证：已有会话的原生 ID 与历史、目录与模型能力、队列和 Steer、停止、审批及断线恢复。涉及真实写操作和模型使用的用例必须显式启用，不能将未知结果自动重发。

0.4 最近一次二十次切换验收覆盖的是桌面端会话；CLI 历史和完整生成控制闭环仍待单独验收。原生拒绝、上游服务错误、仅提交成功或设备页在线均不作为闭环通过证据。

接入和恢复见 [cli-install-implementation.md](cli-install-implementation.md)。
