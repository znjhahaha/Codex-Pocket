## 固定质量门槛

- 手机端状态必须分开记录配置、监听、外层连接、TLS 身份认证、设备 hello 与业务会话；不能把较早阶段冒充最终成功。
- 原生结果未确认时自动核对，同一命令不自动重发，不阻塞无关问题与聊天。
- 不停止原生 Codex 或运行中的模型；无法安全交接的旧组件明确等待重启。
- 保留电脑身份、授权、配对、草稿、现有 AWS 配置和旧交付；所有状态读写验证真实物理路径，拒绝 MSIX LocalCache 重定向。
- 不新增真实模型生成测试、不买资源、不部署 TURN、不强制推送、不发布正式 Release 或标签。生产中继修改已获授权，需基于真实部署核验并保留回滚。
- 同签名 APK、Windows Setup、便携包、源码和 SHA-256 放入新的交付目录。每次包需对应明确源码与实际测试记录。
- 真实登录、真机、隔离 NAT、P95 与资源测量未执行时明确列为未验证，不以模拟器或本地夹具替代。
