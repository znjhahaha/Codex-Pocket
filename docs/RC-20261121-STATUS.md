# 2026-11-21 当前代码与验收范围

本次提交汇集原生会话接入、历史读取、Windows 更新恢复、助理任务模型与 Android 交互的本地开发改动。已安装验收的组合为 Windows `0.7.1-rc.20261121.43` 和 Android `0.7.1-rc.20261121.46`（versionCode 48），沿用现有协议、账号、配对和原生会话。

## 本轮交付行为

- Windows 安装后处理运行于管理器目录外；覆盖安装和同版本重装能够重新启动 Pocket 后台。原生任务进程按真实归属保留。
- 尚未派发的会话恢复请求，在唯一在线执行端确认后直接恢复原会话控制；不重新执行未知操作，不复制或分支原会话。
- 手机快速滑到末尾后自动展开输入栏。历史思考摘要隐藏，仅在当前执行的最新位置显示原生提供的摘要。
- 命令默认展示实际脚本，完整启动命令保留在详情。
- 图片刷新由仓库持有生命周期，按原图片槽位更新，保留正文、历史分页和阅读位置。
- 回到底部按钮运行时显示依次弹跳的三点；多图片连续扇开为网格，展开 220 毫秒、收起 360 毫秒，动画不改变外框高度。
