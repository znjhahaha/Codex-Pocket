# Windows 安装与后台恢复

本次修改让安装流程先停止经身份核对的 Pocket 后台、桥接和关联进程，再安装并重启。安装后核对新进程代次、本机认证接口及已经配置的助理连接；失败时保留原始结果和恢复记录。

完整安装会关闭并重新打开关联的 Codex 桌面，当前任务可能中断。安装欢迎页已明确提示，应先保存工作。后台单独恢复可以保留现有 Codex 窗口及其桥接进程。

保存的 Codex 程序路径只在原文件确实缺失、官方同一 MSIX 包家族存在唯一兼容新版本且原 Host/native 已退出时迁移。保持配置库、账号来源、配对、聊天及未知操作记录。未确认的请求不会自动重发。

冷恢复首次附着可以采用同一 Host 返回的当前序号和待处理问题快照；明确交接游标或已连接事件流中的缺口仍拒绝。恢复期间允许目录、模型和历史只读请求，以及不刷新令牌的账号状态读取，保留原写入保护。

CLI 启动准备仅对暂时的运行宿主启动失败做有限重试，继续遵守原进程身份与所有权限制。本机 `assistant/status` 提供不含聊天和账号详情的就绪状态。

## 当前限制

2026 年 11 月 12 日的本机恢复最终取得 `ready=true`、`runtimeReady=true` 和正常后台连接，并保留正在使用的 Codex 窗口。但完整安装后首次自动恢复仍需追加重启 Pocket helper；当前就绪不证明这一问题已彻底解决。

按用户要求，收尾阶段没有新增或重复运行测试。此前阶段的检查记录见 `ASSISTANT-COLLABORATION-ACCEPTANCE-20261112.md`；最终源码已完成发布构建。本次 Windows 更新后的手机图片传输没有再次验证。

GitHub 源码推送与安装包发布是独立操作。此次提交不创建新版本发布，也不覆盖现有 0.6.6 发布资产。
