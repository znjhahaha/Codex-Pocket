# Windows 首装本机控制与诊断阶段记录

日期：2026-11-10。外部用户报告仅局域网配置失败，随后截图出现 `state_access / helper_unavailable`，监督/助手缺少有效运行代次。截图不能证明网络不可达、后台进程不存在或具体配置文件损坏。

## 已定位与修复

1. 旧 snapshot 把尚未创建的可选 `desktop/desired.json` 当成读取失败。现在缺失使用未设置状态，损坏/权限/重定向仍显示真实错误；必需 `config.json` 单独区分缺失、格式、权限与 I/O。
2. 手动开启远控曾先读/运行 Windows 计划任务，导致可选集成故障阻止本机控制启动。现在手动打开窗口后台校验并启动当前安装的 supervisor，开启远控走相同程序入口。窗口显示不等待文件摘要校验；登录任务查询后台单飞并缓存结果/失败，不阻塞线路快照。
3. 启动本机控制不修改远控暂停偏好；显式启用失败恢复之前偏好。重复开启仍由已有监督进程的用户锁和状态锁保护，不结束旧后台或原生模型任务。启动请求提交只表示进程创建被请求，不表示连接成功。
4. 路线准备、互斥、请求写入、助手执行、线路读取分别显示阶段和固定错误码，保留 OS/退出码与操作编号；脱敏操作失败存入用户诊断目录，未知原文/路径/配置不进入导出。
5. agent 早期失败记录 state_path/state_access/state_lock/config/identity/broker/control_bind。监督进程为每次 child 启动生成独立 UUID，匹配 operationId、PID、实际安装代次及时间窗；仅读取有界脱敏字段，旧记录不能冒充当前失败。状态目录无法写入时可从本次拥有的 stderr 管道取得同样记录。只有已认证且匹配当前 child 的新鲜控制状态能清除显示。
6. `run` 要求现有完整身份；缺失/部分身份只报告，不重新生成。明确初始化仍由 `init` 完成。
7. 安装可选集成提供固定四项修复（唯一入口、旧入口清理、登录任务），校验当前清单和代次，同操作编号查询/去重，范围外状态不改动。原始 COM HRESULT 保留；旧安装脚本不支持时显示不支持，不代跑完整安装冒充单项修复。
