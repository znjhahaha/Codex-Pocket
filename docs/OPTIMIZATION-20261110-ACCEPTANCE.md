## 本批实现

| 范围 | 实现与边界 |
| --- | --- |
| 首页加载 | 自动返回采用 30 秒目录有效期；相同请求合并；有缓存不显示阻塞加载；绝对超时／取消均收尾。显式刷新仍重新核对运行时元数据。连接状态与目录错误分离。 |
| 阅读与滚动 | 复用会话窗口、分页和草稿；触摸、内层命令滚动及边界拉伸暂停追尾；只有真实拖动到尾部恢复跟随。结构合并后的锚点立即保存。 |
| 文件呈现 | Markdown 文件语言／网页图标不修改复制文本或原点击范围；已结束轮次显示唯一文件数、实际增删行数、展开和差异入口。累计原生差异优先；只有编辑记录时明确标注，二进制／缺失行数不伪造统计。没有安全文件撤销接口，未提供撤销。 |
| 图片读取 | 历史正在追加时只索引完整 JSONL 记录，并核对已索引前缀摘要；原生会话／turn／item／图片序号校验不变。临时恢复失败后刷新会话仍保留可重试的历史引用；手机重连重读失败图片，负缓存保留原错误和连接代次，下载任务和临时文件按连接代次隔离，迟到旧响应不发布，完成／取消后清理，路径图片的磁盘缓存可离线查看。 |
| 安装 | 单 Pocket 入口、稳定图标、按摘要与目标迁移旧链接；COM 阶段／调用／HRESULT 持久记录；可选集成失败保留核心并可补修。截图电脑原始 COM 根因仍需该电脑的新持久日志。 |
| 升级 | 显示安装／实际运行代次；独立协调程序和持久状态机具备故障夹具。实际 agent／bridge 尚无安全交接 adapter，真实运行只会进入 waiting_restart，未伪报热升级成功。 |
| 暂停远控 | 监督进程保留本机控制；通过已验证 desired 状态关闭手机入口，等待新鲜助手回执后确认暂停，不终止原生任务。 |
| LAN | 共用 Windows 网卡清单、保留多物理 LAN 候选、保留公网配置；mdns-sd 接替手写广播；监听、广播、外层连接、TLS 和设备会话分别记录。 |
| 传输 | 端能力协商后分块回复；有界重组、序号和尺寸验证；旧端保持完整回复。LAN 的 250ms 先行与并行中继竞速由确定性夹具覆盖。 |
| P2P | 锁定 libdatachannel/libjuice，完成 Windows 本地 DataChannel 双向字节校验与 Android arm64 交叉编译。未接入产品 TLS、JNI、认证信令或公网选路。 |
| 助理 | SQLite 任务／事件／记忆、目录写互斥、接管暂停与未知结果核对核心。CLI 调度运行时、聊天入口及定时设置尚未接入。 |
