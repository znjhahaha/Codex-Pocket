# 口袋助理：直接聊天的界面改版

用户要求：像微信里直接和助理聊天，重排 UI、改善 UX，并重设计助理图标。改动限 Android 助理及其入口；复用现有真实消息、任务、提问、审批、记忆和定时 API。

## 选择

比较三个方向：保留四页签的控制台改版；单一聊天页加按需展开的工具；独立聊天列表加多个助理。选择第二个：进入就看到消息和输入框，符合本次“一直和一个助理对话”的目标。已有任务能力放在消息中；管理功能通过明确的入口进入。

## 布局与行为

- 顶部：左侧返回、助理名称及真实状态、右侧更多。去掉常驻四页签和大型入口图标。更多包含全部任务、记忆、定时、设置、原协调对话和刷新。
- 消息：浅灰背景、左侧白色助理气泡及小头像、右侧浅绿色用户气泡，时间按间隔显示。长文仍支持 Markdown、代码及现有深度链接。没有内容时只给简短招呼和填写草稿的建议，不伪造历史或发送消息。
- 执行：任务以紧凑气泡展示状态和标题，点击展开详情、暂停和原对话；结果紧随对应任务。待回答或审批仍显示真实问题及独立按钮，不让普通聊天发送代替授权。
- 输入：底部固定“＋ / 多行输入 / 发送”。“＋”展开项目、任务、记忆、定时工具。项目只在选中或失效时显示紧凑上下文条；保留电脑确认过的会话范围。
- 发送：草稿可编辑；发送受原有在线、启用、状态确认和权限限制。收到真实回执才清除相同草稿；错误保留草稿，等待时阻止重复发送。不因输入建议、菜单或切换页面自动发起执行。
- 导航：记忆、定时和设置作为子页，返回先回助理聊天，保留草稿、项目和滚动位置；退出助理回原来的手机页面。
- 滚动：初次进入落到最新内容；贴近底部才跟随新消息，翻看历史时出现“回到最新”入口；状态更新不抢走阅读位置。
- 图标：原创口袋与对话头像，同一套圆角细线操作图标，48dp 最小点击范围。首页入口保持原 60dp 点击范围。色彩使用助理局部语义变量，适配深色，不改全局主题和系统启动图标。

## 实现计划

1. 主代理拆出助理聊天区与消息呈现函数，重做顶栏、更多菜单、工具面板和子页返回。保留现有所有动作校验、原生问题组件和数据源。
2. 图标子代理实现 `AssistantVisuals.kt` 与 `AssistantPocketButton.kt`，接口固定后由主代理集成。
3. 参考研究子代理整理 BaoCode、Superagent 的已验证公开证据及可借鉴模式，注明不能确认的实现。
4. 更新现有助理交互测试，覆盖导航往返、草稿与项目保留、重复发送、审批隔离、离线、深色、大字和窄屏。使用确定性数据；不发起真实模型任务。
5. 构建同签名 Android 候选，在已授权 MuMu 中检查实际画面及键盘/滚动行为，保存截图和测试记录。现有配对与历史保持原样。

## 验收边界

这是助理的界面与交互改版。Windows 最终安装、真实冷开机首发及公网链路仍由原续作分别记录，不能用 UI 夹具或构建成功替代。

## 已核验的参考

- DeepSeek `dsh-superagent-prototype` `8c32a9dc5d72c033816c6a8110b37f40cf94fba4`：待处理事项优先、直接回答/处理、内部细节折叠。它是监督面板，不能据此称其为手机聊天应用。
- DeerFlow `c8d5c108f326fbc59c7063417d29f8fe8d7c60dc`：独立人机提问、工具审批、默认折叠子任务卡片。
