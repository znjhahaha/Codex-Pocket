## 本轮补充修复

- 历史子代理重新启用按新执行周期计数；旧回合的迟到完成事件不能关闭新周期。
- 多图展开和收起保持同一容器尺寸，过渡只绘制一组内容；慢速解码和快速反向操作不改变后续正文位置。
- 旧协议没有最终回答标记时，仅把成功结束回合的最后一条助手消息视为最终结果；原生明确标记的多个最终片段全部保留。不会按“继续”等文本猜测任务关系。
- 提问卡片在首次测量后发生可见区域变化时不再取消自身入场动画；过渡保持最终布局高度。
- 管理页使用页内液态玻璃分段栏：电脑连接、扩展管理、应用设置。三页分别保存滚动位置，切换运行时时不复用其他实例的列表或错误；保留连接诊断、授权管理、外观和通知设置。
- 扩展目录补充原生已安装应用的只读状态。未公布应用启停能力时明确提示在电脑端管理；未取得目录不显示为零个应用。
- 扫码识别后暂停取景并显示连接／取消确认，确认前再次校验有效期；取消恢复扫码，不提前写入配对。
- 行内代码清除 Markwon 默认矩形背景，圆角背景水平扩展 4dp；保留原文与选择位置。计划正文使用同一结构化表格，底部确认区域补齐键盘和系统导航避让。
- 玻璃降低底色和模糊强度；按用户最后选择恢复细柔的左上角边缘高光。点击移除三层圆形光斑，改为整层轻微透亮与按压形变，保留真实背景采样。
- 短暂通知拥塞从立即断线改为有界等待，增加队列来源诊断。持续积压仍安全断开并恢复，不扩大缓存、不跳过游标、不重发未知写操作。
- 展开工具输出使用浅深主题适配的圆角细边框与独立阅读背景；顶部显示 Shell／工具名称及紧凑的换行、复制入口，取代独占一行的换行胶囊。主会话与子代理共用框架。
- 用户消息下方增加原生发送时间，与复制／编辑同列。原生条目缺少时间时，仅初始提问可使用原生回合开始时间，并在无障碍说明中区分；插话和无可靠时间的历史不套用刷新时间。
- 补齐原生 `userMessage.startedAtMs` 的读取，修正任务内插话已带时间但手机留空的问题。实际 `thread/turns/list` 证明该字段已存在，无需新增历史扫描或更新电脑助手。
- 左上角高光从固定半径内绘弧线改为实际形状轮廓上的渐隐细线；12dp 预览、22dp 模型面板和圆形按钮共用轮廓，不把高光绘入正文区域。

- 缩略栏短按与长按使用触摸事件时间判定，避免繁忙帧的处理延迟把短点按误判成长按。

## 紧凑错误提示补充

- 主会话、子代理和聊天全局错误使用同一紧凑组件：16dp 图标、状态、展开箭头及最多两行原因，取消大面积红底。
- 优先使用原生结构化 HTTP 状态；HTML 错误页面只在默认视图显示简短原因，例如“上游连接超时 · HTTP 522”。原始内容保持不变。
- 点击原位展开纯文本详情，内部滚动最多 200dp；预览最多 16K 字符，复制仍获取完整错误。不执行 HTML，也不从展开操作重发请求。
- 仅原生 `willRetry` 和当前运行回合共同确认时显示“正在重新连接”；重试次数只有原生错误明确提供时显示。终态或后续输出结束旧重连标记。
- 回合结束与历史快照保存原生错误元数据，避免从实时错误切到历史后丢失错误码。本轮只修正 Android 展示，电脑助手和中转不变。
