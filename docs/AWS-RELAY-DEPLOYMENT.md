## 部署与安全

- 使用现有中继源码离线构建；六个 Rust 源文件的远端 SHA-256 与本地一致。
- 容器为非 root、只读文件系统、移除全部 capabilities，限制 128MiB 内存、0.5 CPU 和 64 PID；服务端口只在内部 Docker 网络可达。
- HTTPS 由宿主 Caddy 提供，使用有效的 Let's Encrypt IP 证书；六小时续期检查定时器已启用，续期演练及部署钩子通过。
- 此环境的 Docker 29 内部网络没有建立宿主发布端口，代理改为访问固定的内部容器地址；IP 客户端不发送 SNI，Caddy 显式配置默认 SNI。两项均通过独立检查验证。
- 服务器只保留中继角色令牌哈希；电脑身份私钥、配对授权和模型凭据未上传。验证使用的临时房间已移除。
