## 本批实现与证据

- 单入口：新安装只创建 `Codex Pocket`；旧第二入口仅在安装记录摘要及 Shell Link 目标／参数同时匹配时迁移。保留版本 3 三项记录顺序及旧回滚契约。图标取自现有原创 Pocket 资源，放在安装树下不可变的摘要资源目录。
- Windows Shell Link：统一通过 IShellLinkW/IPersistFile 写入、回读目标、参数、图标；不再用 WScript.Shell 创建入口。
- 安装诊断：持久操作 ID、阶段、具体调用、HRESULT、安全异常类型和回滚结果；保留内层 COM 调用，避免外层阶段覆盖根因。不记录原始异常消息或凭据。
- 桌面诊断：安装摘要与运行代次分开；运行证据核对 PID、创建时间、可执行文件路径、安装清单和程序摘要。旧版本缺少证据显示未核验。`routes/read` 失败保留问题项；控制命令错误保留安全分类和退出码。
- 中文 NSIS：通用失败消息不再引导安装 WebView2；编译输入使用 UTF-8 BOM，修正中文脚本编码失败。
- 截至本批：Rust 工作区全量初始检查通过；后续桌面运行时／Tauri 回归通过；前端 79 项、Playwright 29 项通过；Windows 安装夹具 23 项、嵌套 COM 诊断夹具通过；中文 NSIS 打包和输入篡改拒绝夹具通过。
- Android：缓存、分页、局部加载、扩展列表以及滚动手势仍在集成验证；未将早期失败的滚动测试标为通过。最终结果与交付哈希另行补录。
